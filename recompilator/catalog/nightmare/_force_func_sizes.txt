# Explicit N64Recomp function-size overrides (consumed by gen_toml.py).
# A size here makes the function's recompiled extent SPAN past its carved ELF symbol so an internal
# jump table whose case labels live in the carved tail can size correctly (in-function `goto`s) instead
# of failing to size -> live-gap stub -> interpreter derail -> run-queue corruption -> crash.
#
# func_80080808 = NC's __osException dispatch head. Its jr/jtbl_80003400 (at 0x80080A54) indexes INTERIOR
# labels of the dispatch tail (L_80080A98/AF0/C3C/CA0/CC4/D00 + in-head A5C/A68/A74), but symbol_addrs
# carved that tail into func_80080A88/B84/C7C so the runtime's SEPARATE `jr $s2` (0x80080E30) func-pointer
# dispatch can LOOKUP_FUNC those handler STARTS. Extend the head to 0x80080D34 (= func_80080D34 start) so
# all 9 jtbl cases are in-function; the carved siblings stay separately recompiled (they overlap — fine).
# 0x80080D34 - 0x80080808 = 0x52C.
func_80080808 = 0x52C
# The three carved cause-handler fragments. Their EXACT carved sizes are pinned so the severed-function
# auto-extension neither extends them NOR (critically) lets func_80080A88's falls-off-end extension absorb
# func_80080B84/C7C (which left B84/C7C with NO standalone body -> the runtime jr-$s2 dispatch fell into the
# interpreter -> derail -> run-queue corruption). With exact sizes each is recompiled standalone; its
# `b L_80080A24` dispatch loop-back is emitted via the recompiler's static-loop mechanism (static_..._80080A24).
func_80080A88 = 0xFC
func_80080B84 = 0xF8
func_80080C7C = 0xB8
